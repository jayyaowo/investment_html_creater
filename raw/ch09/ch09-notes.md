# Chapter 9: Behavioral Finance and Technical Analysis (行為財務學與技術分析)

## 1. 行為財務學兩大支柱 (Behavioral Critique of EMH)
行為財務學主張即使存在錯誤定價，市場價格也未必能回歸基本面價值，原因來自兩大結構性障礙：
- **第一支柱：非理性資訊處理 (Information Processing Errors)**
  1. **預測誤差 (Forecasting Errors)**：過度看重近期經驗（近因偏誤）而忽略長期基準機率。
  2. **過度自信 (Overconfidence)**：投資人高估自己預測能力與資訊準確度，導致過度交易並降低淨報酬。
  3. **保守主義偏誤 (Conservatism)**：對新資訊反應過慢，導致股價在盈餘公告後出現緩慢調整（解釋 Ch.8 的 PEAD 異象）。
  4. **樣本數忽略與代表性偏誤 (Sample Size Neglect & Representativeness)**：誤將短期連續漲跌視為長期趨勢（導致價格過度反應與後續反轉）。
- **第二支柱：行為偏誤 (Behavioral Biases)**
  1. **框架效應 (Framing)**：決策受問題呈現方式影響（例如將結果框定為「獲利」或「損失」）。
  2. **心理帳戶 (Mental Accounting)**：將不同來源或用途的資金分開管理，違背投資組合整體最佳化原則（直接衝擊 Ch.6 Markowitz 模型）。
  3. **後悔規避 (Regret Avoidance)**：害怕做出非傳統決策後承擔後悔感，導致羊群效應 (Herding)。
  4. **處分效果 (Disposition Effect)**：過早賣出獲利股票（鎖定獲利）、過久抱牢虧損股票（逃避實現損失）。
  5. **展望理論 (Prospect Theory)**：由 Kahneman 與 Tversky 提出，認為投資人效用取決於相對於參考點的「財富變動量」而非最終財富水準；且損失帶來的痛苦遠大於等額獲利的快樂（損失規避, Loss Aversion），效用函數在獲利區呈凹性（風險趨避）、在損失區呈凸性（風險愛好）。

## 2. 套利限制 (Limits to Arbitrage)
為何理性套利者無法完全消除非理性投資人造成的價格偏離？
- **基本面風險 (Fundamental Risk)**：在價格回歸內含價值前，公司基本面可能發生新的惡化。
- **執行成本與放空限制 (Implementation Costs)**：交易手續費、借券成本與放空限制阻礙套利。
- **模型風險 (Model Risk)**：錯誤定價可能源自定價模型本身設定錯誤，而非真正的套利機會。
- **噪音交易者風險 (Noise Trader Risk)**：非理性情緒可能在短期內進一步惡化，迫使套利者在價格回歸前因保證金追繳而提前平倉認賠（典型案例：雙重上市公司 Royal Dutch 與 Shell 的長期價差偏離）。

## 3. 技術分析與行為金融的連結 (Technical Analysis)
- 技術分析試圖從歷史價格趨勢、支撐線／壓力線與市場情緒指標中尋找規律。
- 行為財務學為部分技術現象提供心理學解釋（例如處分效果與參考點錨定形成價格阻力位），但實證上仍須謹慎看待交易成本與資料探勘偏誤 (Data Mining)。
